# Unit-Testing
Unit testing is the process of testing small, individual parts of an application, such as functions or methods, to make sure they work correctl


#Key Points
-Used to test individual functions or small pieces of code.
-Helps detect bugs early during development.
-pytest is a popular Python framework used for writing and running unit tests.
-assert is used to check whether the actual result matches the expected result.
-Fixtures are reusable functions used to provide common test data or setup for tests.
-Unit tests can be automated and executed using a simple command.
